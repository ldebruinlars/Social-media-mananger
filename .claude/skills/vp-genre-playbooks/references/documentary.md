# 다큐 · 지식 플레이북 (우주 · 공법 · 국뽕 · 미드폼/롱폼)

| 축 | 값 |
|---|---|
| 조명 | `natural motivated light` — 광원을 화면 안에 두거나 방향을 명시. 스튜디오 룩 금지 |
| 카메라 | 고정 또는 아주 느린 push-in. **관찰자 거리** 유지 |
| 색 | `neutral grade, slightly desaturated, natural skin tones` — 과장 금지 |
| 구도 | 대상이 화면에서 차지하는 **면적 분수**를 명시 |
| 오디오 | 전부 off — 나레이션·SFX·BGM은 후반 |

## 다큐 인서트(X레이·인포그래픽·주석)
🔴 **새로 만들지 말고 정본을 써라** = `(not in this pack)` (전 채널 공용).
투시·해부·바이오메카닉스·프리즈프레임 분석·포인트 주석이 전부 여기 있다.
- 인서트는 **16:9** — 미드폼/롱폼은 가로다
- 공법 쇼츠 오버레이는 **SFX + 해결사 + 하중** 3요소 (Remotion으로 강제)

## 포맷 규격 (실수 1순위)
| 포맷 | 길이 | 화면 | 해상도 |
|---|---|---|---|
| shorts | ~45초 | 9:16 세로 | 720p |
| midform | 5~6분 | 16:9 가로 | 1080p |
| longform | 8~9분 | 16:9 가로 | 1080p |

🔴 **미드폼은 쇼츠 상수를 물려받는다** — 캔버스·duration 상수를 반드시 감사하라.
🔴 **미드폼 5분 = 30~36섹션** (CPS 함정: 계획표 글자수와 실측 낭독 길이가 다르다).
🔴 챕터 제목은 **분위기 라벨이 아니라 검색 키워드**.

## 프롬프트 골격
```
Static camera shot, eye-level, <대상> fills the <면적 분수> of the frame.
<대상 서술> <완결동작 1개, 끝상태>. <환경>, natural motivated light from <방향>,
neutral grade, slightly desaturated, fine grain.
The camera does not move. The only movement is <앰비언트>.
```

## 롱폼 규율
- 🔴 롱폼 저조는 **길이가 아니라 톤** 문제다 — 러닝타임 만지기 전에 "시청>길이" 편수부터 보라
- 획득감(value_takeaway) 1개 필수 — "응 잘봤어"로 끝나면 실패
