# VFX · 전환 문법

> 🔴 **착수 전 필독 — [실패 정본 `vp-failure-registry`](../vp-failure-registry/SKILL.md)**
> 이 스킬의 규칙은 전부 **실패로 산 것**이다. 반증된 처방 8건·소환 사고 8건·비용 사고 5건이 거기 있다.
> 엔진·코드 실패는 the engine failure log (not included).


> **핵심 판단**: 이 효과를 **모델이 만들어야 하는가, 편집이 만들어야 하는가.**
> 잘못 맡기면 돈만 쓰고 환각을 얻는다.

## 1. 🔴 담당 배분표

| 효과 | 담당 | 이유 |
|---|---|---|
| 유기적 변화 (녹기·타기·젖기·성장) | 🔶 **수미프레임** | 단일 i2v는 **펄싱**(늘었다 줄었다)이 된다 |
| 기하학적 이동 (빔 회전·궤적·등속 점멸) | **ffmpeg** | AI는 발광 이물질을 만든다 |
| 인물 변신·나이 변화 | 🔶 **수미프레임 + 별도 스틸** | 단일 컷에서 정체성이 무너진다 |
| 소멸·등장 | **편집(컷/디졸브)** | 모델은 물체를 "지우지" 못한다 |
| 파티클·연기·불 | ✅ **i2v** | 유기적 — 가장 잘하는 영역 |
| 카메라 전환(컷) | **멀티샷 또는 편집** | `vp-multishot-continuity` |
| 글리치·디지털 왜곡 | **후처리** | 프롬프트로는 재현성 0 |
| 속도 램프 | **후처리** | 발주 길이로 통제 불가 |

## 2. 수미프레임 VFX (i2v의 유일한 변화 도구)

**용도**: 단일 i2v가 못 하는 **비가역 변화**를 만든다.
```
start_image = 상태 A (예: 온전한 얼음)
end_image   = 상태 B (예: 녹은 물)
프롬프트    = 짧게. 과지정 금지.
```
규칙:
- 🔴 **두 프레임이 유사해야** 한다 — 차이가 크면 보간 대신 **하드컷**
- 전환 5초 / 복잡 변형 10초
- 시작 프레임이 **종횡비를 결정**
- 검증된 초단문: `gentle push-in, cinematic continuity, soft lighting carryover`
- **퍼펙트 루프** = 수미에 동일 이미지 + 프롬프트 없음

**지원 모델**: `kling3_0` ✅ · `veo3_1_lite` ✅ · `seedance_2_0`/`mini` ✅ · `seedance1_5` ✅
**미지원**: `kling3_0_turbo` ❌ · `veo3_1` ❌ · `veo3` ❌

## 3. 전환 문법 (컷 사이)

| 전환 | 만드는 법 |
|---|---|
| 하드컷 | 편집 (또는 Kling `multi_prompt` — 지정 초에 정확히 발생) |
| 매치컷 | 두 컷의 **같은 형태·같은 위치**를 스틸 단계에서 설계 |
| 디졸브 | 후처리 |
| 화이트/블랙 아웃 | 후처리 (프롬프트로 요구하면 화면이 뭉개진다) |
| 위프 팬 | `whip-pan` 을 **양쪽 컷 끝/시작에** 넣고 편집에서 붙임 |
| 물체 와이프 | 전경 물체가 프레임을 가리도록 설계 → 편집점 |

🔴 **전환을 프롬프트에 "요구"하지 마라.** `transition to…`, `fade to…` 는 화면을 망친다.
전환은 **두 컷을 설계하고 편집에서 잇는 것**이다.

## 4. 폭발·붕괴·충격

- 회사 라우팅상 **③tier(고난도)** = Seedance std 영역 (🔒봉인 시 studio approval)
- Kling으로 가야 하면: **스틸 단계에서 이미 폭발 순간**을 만들고 i2v는 **짧게(4~5초)** 확장
- 단계 순서를 명시: `expanding … then losing shape into black smoke`
- 부수 효과 필수: `debris thrown outward and falling`, `dust wave rolling along the ground`

## 5. 🔴 하면 안 되는 VFX 요구 (환각 확정)

| 요구 | 결과 |
|---|---|
| 광원의 회전·이동 (등대 빔·서치라이트) | 바다에 불덩이, 하늘에 광구 |
| 번개·일회성 섬광 | 정체불명 광원 생성 |
| 천체 궤도 이동 | 하늘에 광구 |
| 느린 비가역 변화 (단일 컷) | 펄싱 |
| 화면에 읽히는 글자 | 깨진 텍스트 |
| 정확한 개수의 개체 소환 | 수가 안 맞음 |

## 6. 실패 사전

| 증상 | 원인 | 대응 |
|---|---|---|
| 변화가 왕복(펄싱) | 단일 i2v에 비가역 변화 요구 | 수미프레임으로 |
| 수미에서 하드컷 발생 | 두 프레임 차이 과다 | 중간 스틸을 하나 더 만들어 2단계로 |
| 전환이 뭉개짐 | 프롬프트로 전환 요구 | 편집으로 |
| 빛나는 이물질 | 발광체 이동 지시 | 제거 → 후처리 |
| 폭발이 연기만 | 단계 미서술 | 순서 부여 + 부수 효과 |
